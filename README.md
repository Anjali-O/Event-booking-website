# Event Booking Website 🎟️

A Django-based web application for booking event tickets online.

## Features
- User Registration & Login
- Event Listing
- Search & Category Filter
- Add to Cart
- Seat Availability Check
- Payment Simulation
- Seat Number Generation
- Booking History
- Ticket Download

##  Tech Stack

### Backend
- Python  
- Django  

### Frontend
- HTML  
- CSS  
- JavaScript  

### Database
- SQLite  

### Libraries Used
- **jsPDF** – For generating PDF files  
- **html2canvas** – For converting ticket HTML into image format

## Installation

1. Clone the repository
2. Create virtual environment
3. Install dependencies
4. Run migrations
5. Start server

```bash
python manage.py runserver
